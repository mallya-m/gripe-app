Gripe — Track Friction, Not Feelings

You don’t forget what matters.
You forget what annoyed you just enough to ignore.

Gripe is a minimal web app to log frustrations in seconds — and turn them into patterns you can actually act on.

No long journaling. No overthinking. Just log → analyze → act.

 Why Gripe?

You’ve probably had this happen:

A coworker crosses a line… again
A company messes something up… repeatedly
You tolerate something… until it becomes a pattern

But when it’s time to act — you’ve got nothing concrete.
Just a vague memory.

Gripe fixes that.

 What It Does
 Log in <10 seconds
Capture friction instantly, before it fades
📊 Pattern Detection
See what keeps happening, how often, and how intense
🧩 Clarity Over Time
Turn scattered annoyances into structured insight
📄 Export as PDF Timeline
Clean, chronological record when you need proof or clarity
🛠️ Tech Stack
Frontend: React (MERN)
Backend: Node.js + Express
Database: MongoDB
Charts: Chart.js
PDF Export: pdf-lib
Auth: JWT
Deployment:
Client → Vercel
Server → Render
❌ No paid APIs used
🧑‍💻 Run Locally
git clone https://github.com/yourusername/gripe-app
cd gripe-app
Backend
cd server
npm install

Create a .env file:

MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret
PORT=5000
npm run dev
Frontend
cd ../client
npm install
npm start
